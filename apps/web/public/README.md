# Archivos públicos (web)

Coloca aquí el **logo oficial** de emergemos con el nombre exacto:

```
logo.png
```

Recomendaciones:
- Usa la versión **horizontal** del logo (flor + "emergemos medicina integrativa").
- Fondo **transparente** (PNG) para que se vea bien sobre claro y oscuro.
- Alto sugerido: 200–400 px (se escala automáticamente).

En cuanto exista `logo.png`, la app lo mostrará automáticamente en el login y
los encabezados. Si no está, se muestra una versión SVG de respaldo.
